# Hi there, I'm Rafael Rossetti (@VotikaBr) 👋

Full-Stack Developer, Systems Enthusiast & Tech Explorer based in Santa Catarina, Brazil.

I bridge the gap between high-level business software and low-level systems. My work ranges from building responsive web dashboards, custom client websites, and automated administrative systems to compiling custom Linux kernels, maintaining Android source trees, and architecting network infrastructure.

I actively integrate **Artificial Intelligence** into my daily engineering workflow—leveraging modern LLM APIs, building automated fallback architectures, and continuously learning and prototyping with emerging AI-assisted tooling.

---

### 🚀 What I Do

- 🌐 **Web & Business Systems:** Designing and deploying end-to-end web management systems, client dashboards, dynamic interfaces, and database-driven applications.
- 🐧 **Linux & Kernel Tuning:** Compiling custom Linux kernels with optimized preemption and tick rates, patch management, backporting drivers, and debugging low-level behavior.
- 📱 **Android Low-Level / AOSP:** Custom ROM building, maintaining device trees/kernels (Snapdragon CAF), integrating advanced root/kernel frameworks (KernelSU-Next, SUSFS).
- 🤖 **AI-Driven Engineering:** Researching and implementing LLM gateway solutions, smart routing, API rate-limiting strategies, and using generative AI as an active research & development partner.
- 📡 **Networking & Cloud/Infra:** RouterOS network design, mesh architectures, DNS-over-HTTPS (DoH), dual-boot workflows, Docker containerization, and cloud management.
